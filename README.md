## Penjelasan activity

### AboutMe
Menampilkan informasi akun dari pengguna.

### AddBus
Menambahkan bus baru ke dalam sistem.

### AddBusSchedule
Menambahkan jadwal bus baru.

### DetailBus
Menampilkan detail dari bus yang dipilih.

### Login
Digunakan untuk login ke dalam aplikasi.

### Main
Merupakan tampilan utama dari program setelah login.

### ManageBus
Menampilkan daftar bus yang terkait dengan pengguna.

### MakeBooking
Digunakan untuk melakukan pemesanan tempat duduk pada bus.

### Payment
Menampilkan daftar pembayaran yang telah dilakukan.

### Register
Digunakan untuk mendaftarkan akun baru.

### RegisterRenter
Mendaftarkan akun sebagai renter.

## Detail Adapter pada Program

### Adapter
Sebagai kelas adapter umum yang digunakan dalam berbagai bagian program.

### BusArray
Berfungsi sebagai adapter untuk menampilkan daftar bus.

### BusSeat
Berperan sebagai adapter untuk menampilkan daftar kursi yang dipilih pada bus.

### ManageBusArray
Digunakan sebagai adapter untuk menampilkan daftar bus yang terkait dengan pengguna.

### PaymentAdapter
Berfungsi sebagai adapter untuk menampilkan daftar pembayaran yang dilakukan oleh pengguna.

### ScheduleAdapter
Sebagai adapter untuk menampilkan daftar jadwal pada bus.
